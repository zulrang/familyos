# Member Color is FamilyOS-owned, not Google Calendar color

Event Participants are identified by stable Household Member IDs, so presentation
color must not be borrowed from Google `colorId` or attendees. Member Color is a
FamilyOS `#rrggbb` value held only by Active Members; open custom colors (not a
closed pastel palette) keep wall presentation independent of the provider, and
retirement frees a color for reuse without rewriting history.
